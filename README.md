## 🏰 초대장 구성

열면 밤하늘에 궁전 문이 닫혀 있습니다. **문을 두 번 두드리면** 문이 열리고, 호박이 "쇼로롱~" 하고 마차로 변합니다. 마차 창문에는 그 초대장의 주인공 공주가 타고 있습니다. 마차가 지나가면 초대장이 나타납니다.

급할 때는 아래 **그냥 바로 보기** 버튼으로 건너뛸 수 있습니다.

### 담긴 내용

- 일시 · 장소 · 드레스코드 · 챙길 것
- **선물 교환식** — 망한 선물(5,000원 이하) + 갓 선물, 제비뽑기로 두 번 교환
- **목표 케이크** — 금색 깃발에 20대에 이룬 것, 분홍 깃발에 30대 목표
- 파티 날까지 남은 날짜 자동 표시
